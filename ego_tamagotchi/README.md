# EGO — машина буста EGO для Flipper Zero

EGO показано как инструмент (Око Ра), вы его оператор. Одна шкала **0–11000**. Поднимать, ловить выход из EGO, видеть слив и спад. Без драмы и без морали. В списке приложений Flipper (Apps → Games) у приложения свой значок-око.

## Заставка

Глаз открывается, смотрит вниз и лучом выжигает на экране **EGO** блок за блоком, в конце вспышка рамки. Любая клавиша пропускает.

## Клавиши главного экрана

| Клавиша | Что |
|---|---|
| ОК | задания |
| **Влево** | модуль ДЕНЬГИ: копилка и день с дочерью |
| **Вниз** | модуль КОНТРОЛЬ: привычки; **вверх** от первой строки это «ВЫХОД ИЗ EGO» |
| Удержание ОК | возврат в EGO, пока вы вне |
| Вправо | сон |
| Вверх | профиль (4 страницы) |
| Назад | выход из приложения |

## Модуль ДЕНЬГИ (влево)

Шкала копилки (цель 200К, старт 70К) и четыре строки. Вверх/вниз выбирают строку, **короткое ОК делает то, что в ней написано**, подсказка внизу экрана:

| Строка | ОК |
|---|---|
| ПОПОЛНИЛ +N К | положить в копилку (первое пополнение за сутки +5 EGO) |
| СНЯЛ -N К | взять из копилки |
| ШАГ N К | сменить шаг 1…5К |
| ДОЧЬ СЕГОДНЯ ДА/НЕТ | включить или выключить день с дочерью (в такие дни в бонус-слот встаёт «Время с дочерью»; дальше день сам раз в 3 дня) |

## Модуль КОНТРОЛЬ: привычки и выход из EGO в одном месте

Раньше выход был в одно движение, сейчас так же быстро, но с защитой от случайного нажатия: **защита это удержание ОК**, а не отдельный вопрос.

| Строка | Короткое ОК | Удержание ОК |
|---|---|---|
| ЗАМЕТИЛ +1 (до 10 в день) | записать | то же |
| УДЕРЖАЛСЯ +3 (до 7 в день) | записать | то же |
| СРЫВ (−5 с множителем) | записать срыв | **срыв и сразу таймер ухода** |
| ВЫХОД ИЗ EGO (вверх от первой строки) | подсказка | **таймер ухода** |

Срыв это сам по себе уход из EGO, поэтому удержание на нём запускает таймер, а возврат (удержание ОК на главном) его закрывает. Не чаще раза в 10 минут на каждое действие. **Бонус за сокращение:** срывов меньше, чем вчера: +2 за каждый срыв разницы (до 10) при закрытии суток.

## Выход из EGO, сжигание, возврат

- Таймер «ВНЕ EGO», без меню и причин. Всё закрыто, кроме таймера и удержания ОК.
- Сжигание: каждые 5 минут −2, после получаса −5 (с множителем на момент выхода), ниже основания не горит, потолок эпизода 25. Идёт по часам даже без экрана.
- **Возврат:** до 5 минут вернётся 100% сгоревшего, до 15 минут 50%, позже 25%, плюс 1.
- После возврата необязательные **причины**: «Анализ» и «Выход из EGO», каждая с небольшим штрафом. Назад = без причин.
- **Основание** раз в сутки подтягивается к EGO (до 8 за круг), если закрыто хотя бы 5 пунктов минимума.

## Ранги, круги, степени S

Круг = **1000** очков, всего **11 кругов** (максимум 11 000).

| Ранг | EGO в круге | Название |
|---|---|---|
| E | 0–149 | КРИТИЧЕСКИЙ (E РАНГ) |
| D | 150–299 | СЛАБЫЙ (D РАНГ) |
| C | 300–499 | СРЕДНИЙ (C РАНГ) |
| B | 500–699 | СТАБИЛЬНЫЙ (B РАНГ) |
| A | 700–899 | ВЫСОКИЙ (A РАНГ) |
| S | 900–999 | ВЫСШИЙ (S РАНГ) |

Собрали круг: ранг S получает степень (S I … S XI), ранги идут по кругу ещё раз (`C II`). Пик хранится. Баннер «EGO КРИТИЧЕСКИ ОСЛАБЕЛО» ниже 300. Старт: EGO 300.

**Штрафы растут вместе с EGO:** множитель = (1 + 0.25 за круг) × полоса (E, D ×0.5 … S ×1.5). Награды прежние.

## Задания и нагрузка

16 ежедневных пунктов, каждый один раз в сутки. Удержание ОК = сделано. У заданий с таймером короткое ОК запускает отсчёт, в конце вибрация, засчёт сам, затем вопрос про потоковость.

| Задание | Очки | Нагрузка (старт, потолок, шаг) | Минимум |
|---|---|---|---|
| Подъём (закрывается «встал» на экране сна) | +3 | | |
| Дыхание | +2 | 20 мин, до 40, +1 | ! |
| Душ | +2 | | |
| Завтрак | +2 | | ! |
| Отжимания | +3 | 30, до 100, +1 | ! (вместе с приседаниями) |
| Приседания | +3 | 25, до 100, +1 | ! |
| **Код** | **+11** | 45 мин, до 120, +2 (+5 за круг) | |
| Читать код | +6 | 30 мин, до 90, +2 | |
| Обед | +2 | | ! |
| Архитектура | +5 | 20 мин, до 60, +1 | |
| Время себе | +4 | 30 мин, до 90, +2 | ! |
| Медитация | +4 | 15 мин, до 40, +1 | ! |
| Внимание на себе | +3 | | |
| Моё желание | +5 | | |
| Ужин | +2 | | ! |
| Индивидуализация | +4 | | |

**Нагрузка растёт сама:** на шаг за каждые 2 выполненных дня, два пропуска подряд откатывают шаг (не ниже стартовой). **Взять нагрузку сразу:** на экране заданий клавиша **влево** добавляет шаг выбранному заданию (если оно ещё не выполнено сегодня и не на потолке).

**Минимум дня (!) из 8 пунктов:** завтрак, обед, ужин, спорт (отжимания и приседания вместе), время себе, медитация, дыхание + сон зафиксирован. Не закрыт к концу суток (граница 05:00): штраф **8 за пункт** (с множителем). Пауза (профиль, данные, удержание ОК) отменяет штраф за сутки.

**Бонусы:** 3 в день из ротации в 35 пунктов, пропуск бесплатный:
- *Позиция:* сказал, что хочу; «нет», не объясняя; мнение первым; пауза до ответа; без извинений; не ждал оценки; не стал угождать; взял своё время; выбрал себя.
- *Деньги:* потратил на себя; деньги: действие; назвал цену; написал клиенту.
- *Дела:* отправил готовое; закрыл старое; начал с трудного; показал работу; понял решение; нарисовал схему; записал идею; объяснил систему; улучшил код; написал тест; нашёл баг; решил за 5 минут; порядок на столе; план дня строкой.
- *Тишина и энергия:* прогулка тихо; музыка: делал; слушал музыку; общение: игра.
- *Тело:* холодный душ; растяжка; вода утром; прогулка 30 мин.

**Время с дочерью** (+6): в дни с дочерью первый бонус-слот (ДЕНЬГИ → «ДОЧЬ СЕГОДНЯ»; дальше сама раз в 3 дня).

**Перенос** ядра: первый бесплатный, дальше −0.5 (копится), после трёх задание снимается с дня. Списки и очки в `ego_data.c` (`k_pool`).

## Сон

Вправо на главном. Лёг и встал двумя нажатиями; куски за ночь **складываются за 24 часа** (ночи с ребёнком рваные). Вверх/вниз на экране сна: поправка 30 минут. 7+ часов +8, 6 часов +5, 5 часов +3; от 3 часов сон считается зафиксированным. «Встал» закрывает «Подъём». Окна дня считаются **от подъёма**, пока вы спите, дежурный режим молчит.

## Профиль (вверх, влево/вправо страницы)

0. **Логотип смотрит прямо**, ранг, круг, пик, до следующего ранга, множитель штрафов.
1. **Герой:** Тело, Дела, Деньги, Позиция, Тишина с уровнями (10 выполнений = уровень) и **копилка 200К** (только показ; управление в модуле ДЕНЬГИ на «влево»).
2. **Данные:** проверки, возвраты, привычки, сон, дежурный режим (ОК), пауза (удержание ОК), день с дочерью (показ; переключатель в ДЕНЬГИ).
3. **Динамика:** EGO по суткам внутри круга, прирост и слив.

## Дежурный режим (пуши)

Включается в профиле (страница 2, ОК). Приложение остаётся открытым, экран гаснет, и оно само:
- **потоковость** раз в час, **быть в EGO** раз в 1 час 11 минут: «да» +2, вылет или без ответа за 10 минут штраф с множителем;
- раз в час выдаёт карточку задания (ядро, потом бонусы), дедлайн час: ядро переносится само, бонус пропускается;
- проверка и следующая карточка за одну вибрацию.

Приложение Flipper не работает в фоне, без дежурного режима пушей нет.

## Лог событий

`SD Card/apps_data/ego_tamagotchi/ego_log.csv`: `ts,event,id,delta,ego`. События: quest, postpone, load, check, check_fail, check_miss, out, return, burn, cause, miss, habit_notice, habit_hold, habit_slip, habit_reduce, sleep_start, sleep_end, sleep_adjust, savings, daughter, timer, pause, duty.

## Файлы

- `ego_core.*` — логика без Flipper SDK (тест на ПК: `../tests_pc/test_core.c`).
- `ego_data.c` — пул заданий, причины, ранги, римские цифры, направления.
- `ego_draw.*` — Око Ра, анимации, заставка.
- `ego_font.*`, `ego_font_glyphs.c` — свой шрифт 5x7 (кириллица и латиница D S G I V).
- `ego_storage.*` — сохранение и CSV-лог.
- `ego_app.c` — экраны, ввод, дежурный режим, таймеры.
- `icon.png` — значок приложения 10x10.

## Сборка и запуск

```
python -m pip install --upgrade ufbt
python -m ufbt update --index-url=https://up.unleashedflip.com/directory.json --channel=release   # для Unleashed
python -m ufbt            # сборка -> dist/ego_tamagotchi.fap
python -m ufbt launch     # запуск на подключённом Flipper (qFlipper закрыть)
```

Название в меню приложений остаётся латиницей (`EGO`).
